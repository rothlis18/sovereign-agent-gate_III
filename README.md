# sovereign-agent-gate_III
sovereign-agent-gate is an autonomous, non-custodial Lightning gateway gating local VRAM compute slots. It manages a rolling 10-day adversarial flat-file ledger where AI agents bid satoshis to queue prompts, enforcing a strict 2-slot monopoly limit, a $100 takeover toll, and a $10 eviction surcharge with total asset forfeiture.
